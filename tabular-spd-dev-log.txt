  Current Performance Profile

  Time Complexity: O(F × P × C) where:

  - C = number of non-empty cells per period (sparse, usually << total grid

  1. Field detection: O(F) - trivial
  2. For each field × period:
    - Sparse→dense conversion (if needed): O(nodes) - potentially expensive
    - Mask creation: O(nodes)
    - np.where(): O(nodes)
    - Record creation: O(C) - cheap since C is sparse
  3. DataFrame creation: O(F × P × C)
  4. Groupby merge: O(F × P × C × log(P × C))

  access a few cells

  4. Groupby: Adds overhead for multi-field packages
